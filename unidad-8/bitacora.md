## 🎨 Paso 1: Definir la idea general

### Tema sugerido

Podemos hacer una **interacción musical visual**: tu celular actúa como “control maestro” (entrada táctil), y el computador muestra en un canvas de p5.js una visualización en tiempo real de formas y colores que responden al tacto, además de reproducir un sonido (o varios sonidos) dependiendo de la posición del toque.
Este tema combina lo que ya viste: toque móvil → servidor → visualización en computador + sonido.

### Elementos del sistema

* **Celular (cliente móvil)**: página web que detecta toques y envía datos (coordenadas, presión, ID) al servidor.
* **Servidor Socket.IO + Node.js**: puente que recibe los datos del móvil y los envía al cliente de escritorio.
* **Computador (cliente escritorio)**: canvas p5.js que recibe los datos del servidor y, según ellos, dibuja y anima formas + reproduce sonido.
* **Visualización**: Podría haber por ejemplo tres círculos que cambian de tamaño y color según la posición del toque; el sonido cambia según la zona del canvas tocada.

### Flujo de datos

1. Tocas en el celular → evento táctil detectado → envío de JSON al servidor.
2. El servidor recibe el JSON y lo transmite a la ventana de escritorio.
3. La ventana de escritorio recibe el JSON y actualiza la animación + sonido.

### 💡 2) **Concepto de las visuales**

El proyecto se llama **“DrawSync”**.
La idea es crear una aplicación web interactiva donde el usuario pueda **dibujar en un canvas del computador usando el celular como control remoto**, y **usar el micro:bit para cambiar el color o el tipo de trazo**.

* En la pantalla del computador aparece un canvas (hecho con **p5.js**) donde se van dibujando líneas o figuras.
* El usuario controla el dibujo desde su **celular**, moviendo el dedo sobre la pantalla.
* El **micro:bit** permite cambiar el color de las líneas con un botón (por ejemplo el botón A) y cambiar la forma (líneas → círculos) con el otro botón (B).

El resultado son visuales simples, dinámicas y personalizables que combinan distintos dispositivos.

---

### 📱 3) **Cómo el móvil y el micro:bit controlan las visuales**

* **Móvil:**
  Se conecta al servidor (por medio de **Socket.IO**) y envía la posición del toque del usuario (`x`, `y`) al computador. Cada movimiento del dedo genera una línea o figura en el canvas.
* **Micro:bit:**
  Conecta al mismo servidor por puerto serial o Bluetooth.

  * Botón **A:** cambia el color del trazo (por ejemplo entre rojo, azul, verde, amarillo).
  * Botón **B:** cambia el modo de dibujo (líneas o círculos).

De esta forma, los tres elementos (móvil, micro:bit y computador) se comunican en tiempo real para generar visuales interactivas.

## 2) `server.js` (reemplaza o añade el que tienes)

```js
// server.js
const express = require('express');
const http = require('http');
const path = require('path');
const { SerialPort } = require('serialport');
const { ReadlineParser } = require('@serialport/parser-readline');

const app = express();
const server = http.createServer(app);
const io = require('socket.io')(server);

// Puerto para HTTP
const PORT = process.env.PORT || 3000;

// Servir carpeta public
app.use(express.static(path.join(__dirname, 'public')));

// ---- Serial (micro:bit) ----
// Ajusta el nombre del puerto si lo conoces (ej: 'COM3' en Windows).
// Si no pones path, el código intentará abrir el primer puerto serial disponible que parezca válido.
// Puedes ponerlo explícito así:
// const SERIAL_PATH = 'COM3';
const SERIAL_PATH = process.env.SERIAL_PORT || null;
let serialPort = null;

async function tryOpenSerial() {
  try {
    if (SERIAL_PATH) {
      serialPort = new SerialPort({ path: SERIAL_PATH, baudRate: 115200 });
    } else {
      // Si no se especifica puerto, intenta abrir el primer puerto que aparezca
      const ports = await SerialPort.list();
      if (ports.length === 0) {
        console.log('No serial ports found.');
        return;
      }
      // Busca un puerto probable (no estrictamente necesario)
      const candidate = ports[0].path;
      serialPort = new SerialPort({ path: candidate, baudRate: 115200 });
      console.log('Opening serial port:', candidate);
    }

    const parser = serialPort.pipe(new ReadlineParser({ delimiter: '\n' }));
    parser.on('data', line => {
      // Esperamos líneas como: x,y,aState,bState
      const trimmed = line.trim();
      if (!trimmed) return;
      // console.log('Serial raw:', trimmed);
      const parts = trimmed.split(',');
      if (parts.length >= 4) {
        const x = parseInt(parts[0]);
        const y = parseInt(parts[1]);
        const aState = parts[2] === 'True' || parts[2] === 'true' || parts[2] === '1' ? true : (parts[2] === 'False' || parts[2] === 'false' || parts[2] === '0' ? false : Boolean(parts[2]));
        const bState = parts[3] === 'True' || parts[3] === 'true' || parts[3] === '1' ? true : (parts[3] === 'False' || parts[3] === 'false' || parts[3] === '0' ? false : Boolean(parts[3]));
        const payload = { x, y, a: aState, b: bState, raw: trimmed, timestamp: Date.now() };
        // Emitir evento a clientes conectados
        io.emit('microbit', payload);
        // opcional: log en servidor
        // console.log('microbit =>', payload);
      }
    });

    serialPort.on('open', () => {
      console.log('Serial port opened.');
    });
    serialPort.on('error', err => {
      console.error('Serial port error:', err.message);
    });
    serialPort.on('close', () => {
      console.log('Serial port closed.');
    });
  } catch (err) {
    console.error('Error opening serial:', err);
  }
}

// Intenta abrir serial al iniciar
tryOpenSerial();

// ---- Socket.IO ----
io.on('connection', socket => {
  console.log('New client connected', socket.id);

  // recibir mensaje de cliente (móvil)
  socket.on('touch', data => {
    // data expected: { x, y, type }
    // Reenviar a todos los clientes (desktop)
    io.emit('touch', data);
  });

  // recibir mensajes genéricos
  socket.on('message', data => {
    console.log('Received message from client', socket.id, data);
  });

  socket.on('disconnect', () => {
    console.log('Client disconnected', socket.id);
  });
});

// Iniciar servidor HTTP
server.listen(PORT, () => {
  console.log(`Server is listening on http://localhost:${PORT}`);
});
```

let drawMode = 'line'; // 'line' or 'circle'
let statusDiv;

  createCanvas(windowWidth, windowHeight);
  background(30);
  statusDiv = document.getElementById('status');

  socket = io();

  socket.on('connect', () => {
    console.log('Connected to server (desktop).');

  });

  // Recibir touch desde mobile
  socket.on('touch', data => {
    if (!data) return;
    if (data.type === 'touch') {
      // Map mobile coords to desktop canvas (simple mapping based on window sizes)
      // If mobile and desktop resolutions differ, you can normalize on client or server.
      // Aquí asumimos que mobile envía tamaño relativo; si no, solo usamos x,y directos.
      let x = data.x;
      let y = data.y;
      // Dibuja y conserva el dibujo (no limpiar fondo)
      drawAt(x, y);
    } else if (data.type === 'end') {
      // opcional
    }
  });

  // Recibir datos del micro:bit (serial->server->emit('microbit'))
  socket.on('microbit', payload => {
    // payload: { x, y, a, b, raw, timestamp }

    if (payload.a) {
      // botón A presionado -> cambiar color (rotar paleta)
      rotateColor();

    if (payload.b) {
      // botón B presionado -> cambiar modo
      toggleMode();

    statusDiv.innerText = `micro:bit a:${payload.a} b:${payload.b}`;

function windowResized() {
  resizeCanvas(windowWidth, windowHeight);
}

function drawAt(x, y) {
  noStroke();
  if (drawMode === 'line') {
    stroke(drawColor);
    strokeWeight(4);
    // Dibujar un segmento pequeño para simular trazo continuo
    // Podemos dibujar un línea desde el último punto, pero para simplicidad solo un punto al punto actual:
    point(x, y);
  } else if (drawMode === 'circle') {
    noStroke();
    fill(drawColor);
    ellipse(x, y, 20, 20);
  }
}

// Utilities
const colors = ['#ff0000', '#00ff00', '#0000ff', '#ffff00', '#ff00ff', '#00ffff', '#ffffff'];
let colorIndex = 0;
function rotateColor() {
  colorIndex = (colorIndex + 1) % colors.length;

  console.log('Color changed to', drawColor);
}

  drawMode = (drawMode === 'line') ? 'circle' : 'line';

### ✅ Solución 1 — Solo dibujar mientras el mouse está presionado

Usa `beginShape()` y `endShape()` para delimitar los trazos, o guarda cada línea como independiente.

Aquí tienes una versión corregida y limpia del sistema de dibujo libre sin uniones indeseadas:

```javascript
let drawing = []; // Guarda todas las líneas
let currentLine = []; // Guarda los puntos de la línea actual

function setup() {
  createCanvas(windowWidth, windowHeight);
  background(255);
}

function draw() {
  background(255);

  // Dibujar todas las líneas anteriores
  stroke(0);
  strokeWeight(3);
  noFill();
  for (let line of drawing) {
    beginShape();
    for (let pt of line) {
      vertex(pt.x, pt.y);
    }
    endShape();
  }

  // Dibujar la línea actual (en curso)
  if (mouseIsPressed) {
    currentLine.push({ x: mouseX, y: mouseY });
  }
}

function mouseReleased() {
  // Cuando sueltas el mouse, guardas la línea y reinicias
  if (currentLine.length > 0) {
    drawing.push(currentLine);
    currentLine = [];
  }
}
```

---

### 🧠 Explicación

* Cada vez que presionas el mouse, se empieza a llenar `currentLine` con puntos.
* Cuando sueltas el mouse (`mouseReleased`), esa línea se “guarda” en `drawing` como un trazo terminado.
* Al dibujar de nuevo, `currentLine` comienza vacía, así que no hay unión entre líneas.
